## 3. Canonical terms: details


### diff analysis
<a id="term-diff-analysis"></a>

Definition: What the engine returns from two texts: the paired line entries in display order and the positions of those holding a change.
Scope: `project`


### dxdiff
<a id="term-dxdiff"></a>

Definition: The class-name prefix on every styling hook, keeping the viewer's classes from colliding with an app's own.
Scope: `project`


### fold row
<a id="term-fold-row"></a>

Definition: The single row standing in for a run of folded unchanged lines, reading "Expand N lines ..." unless the consumer supplies its content.
Scope: `project`


### inline change
<a id="term-inline-change"></a>

Definition: A token removed from or added to a modified line, marked within that line under the selected compare method.
Scope: `project`


### line ending chip
<a id="term-line-ending-chip"></a>

Definition: The compact chip showing a line's terminator as escaped text (`\n`, `\r\n`, `\r`) on each side of a line ending change.
Scope: `project`


### line id
<a id="term-line-id"></a>

Definition: A line's side and number joined by a hyphen, `L` for old and `R` for new, as in `L-20`.
Scope: `project`


### modified line
<a id="term-modified-line"></a>

Definition: A removed line paired in order with the added line immediately following it, shown as one change rather than a removal and an addition.
Scope: `project`


### paired line entry
<a id="term-paired-line-entry"></a>

Definition: One row of a diff analysis: an optional old line and an optional new line with their change kind, as either view reads it.
Scope: `project`


### styling hook
<a id="term-styling-hook"></a>

Definition: A stable `dxdiff`-prefixed class naming an element's kind, view, or state, which apps and themes style against.
Scope: `project`


### whitespace change
<a id="term-whitespace-change"></a>

Definition: A difference only in leading or trailing whitespace between a modified pair's lines, marked under trimmed line comparison.
Scope: `project`


### whitespace chip
<a id="term-whitespace-chip"></a>

Definition: The compact chip reading `WS` on each side's line of a pair carrying a whitespace change.
Scope: `project`
